About the Role

We are looking for an experienced Full Stack Developer to build and maintain scalable web applications, APIs, and backend services.

You will work with Next.js, Node.js, Express.js, MongoDB, PostgreSQL, Salesforce, payment gateways, and AWS infrastructure. You will collaborate with UI/UX, QA, DevOps, and other teams to deliver secure and high-performance applications.

Key Responsibilities

Full Stack Development

Develop and maintain web applications using Next.js, React.js, Redux, Tailwind CSS, and SCSS.
Build and maintain RESTful APIs using Node.js and Express.js.
Design and manage applications using MongoDB and PostgreSQL.
Develop scalable backend services using microservices architecture.
Optimize application performance for desktop and mobile devices.
API & Integrations

Design, develop, and maintain REST APIs.
Create and maintain API documentation using Swagger/OpenAPI.
Develop and manage webhook-based integrations.

Implement payment workflows, callbacks, redirects, webhooks, refunds, and transaction status handling.
Ensure secure and reliable payment processing.
Handle payment failures, duplicate transactions, and reconciliation requirements.
AWS & DevOps

Build and maintain CI/CD pipelines using Jenkins.
Monitor applications and troubleshoot production issues.

Follow coding standards, security best practices, and development processes.
